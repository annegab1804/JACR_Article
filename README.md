
# Radiology FDA Audit

Analytical repository for the FDA Radiology AI 7-Pillar Audit project.

## Structure

- `data/` → raw dataset
- `src/` → reusable analytical toolkit
- `notebooks/` → master notebook
- `output/` → manuscript figures and supplementary materials

## Requirements

Install dependencies:

```bash
pip install -r requirements.txt
```

Run notebook:

```bash
jupyter notebooks/fda_analysis.ipynb
```
